# HORIZON — иммерсивный планетарий (концепт)

Концепт сайта планетария с шоу о чёрных дырах. Планетарий, цены и расписание вымышленные,
факты о чёрных дырах — настоящие.

**Сайт:** https://iaroslaviskendirov-alt.github.io/horizon/

**Стек:** React 19, TypeScript, Vite, Tailwind CSS 4, framer-motion, lucide-react.
Структура в стиле shadcn: компоненты в `src/components/ui`, утилиты в `src/lib`.

## Что внутри
- `etched-accretion.tsx` — чёрная дыра на WebGL2-шейдере: движение мыши меняет ракурс,
  зажатая кнопка «кормит» дыру. Пауза вне экрана, адаптивное качество, статичный кадр
  при «уменьшении движения», запасной рисунок без WebGL2.
- `dock.tsx` — нижняя навигация в стиле macOS (увеличение иконок под курсором).
  Доработано: иконки — настоящие ссылки и кнопки, работают с клавиатуры.
- Кнопка «Цвет диска» в доке переключает 5 пресетов, вместе с диском меняется акцент сайта.
- Билеты: выбор шоу, даты и сеанса (прошедшие сеансы недоступны), подсчёт суммы.

## Запуск
```bash
npm install
npm run dev
```
Публикация — автоматически через GitHub Actions при push в `main`.
